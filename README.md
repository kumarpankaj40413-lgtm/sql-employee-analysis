# 📊 SQL Employee Workforce Analysis

## 🎯 Project Overview
A basic SQL analysis project created using MySQL Workbench to analyze employee workforce demographics, city-wise distribution, and turnover rates.

## 🛠️ Tools & Technologies
* *Database:* MySQL
* *Tool:* MySQL Workbench

## 🔍 Key Queries Covered
* Total employee count
* City-wise employee distribution
* Gender breakdown
* Education level analysis
* Employee turnover (Leave vs Stayed) overview
